> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tipli + yere bağlı ekipman (ev/salon), İngilizce ad birinci sınıf, katalog 26 → ~120 hareket (free-exercise-db iskeleti + araştırılıp yazılan içerik), hareket başına MET/enerji modeli.

**Spec:** `docs/superpowers/specs/2026-08-31-disport-v2-saglikli-yasam.md` §4

enum EquipmentKind {
